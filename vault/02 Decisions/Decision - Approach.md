# Decision: Code picks, AI teaches

## Chosen
1. **Skill map** — Common Core skills with prerequisite links. See [[Skill Map]].
2. **Skill tracker** — code keeps a score per skill per kid and picks the next problem.
3. **Problem maker** — templates with random numbers; code always knows the answer.
4. **Teaching styles** — fixed set (number line, blocks, story, drawing); code learns which works for each kid.
5. **AI** — talks, cheers, hints, explains in the chosen style. Never grades.

## Rejected
- **AI does all** — fast to build, but wrong math, drifts off curriculum, costly, hard to prove learning.
- **Hand-made path** — safe, but slow to author and feels like a worksheet.

## Why
Only option that is correct, feels like a real tutor, and can prove learning (needed later for investors and schools).
