# Rewards Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cubes, levels, a weekly play goal with a week streak, and stickers, worked out from existing session rows and shown on the end card, picker, grown-up child page and weekly email, behind `REWARDS` (off by default).

**Architecture:** A pure module `src/domain/rewards/` turns a kid's finished-session facts (plus `skill_state.mastered_at`) into a `Progress`. A server loader `src/server/rewards.ts` reads only those fields with the caller's Supabase client. The play routes attach `rewards` to an end turn. UI components render it in the DESIGN.md "Math Classroom" world. No migration, no new stored data.

**Tech Stack:** Next.js 16 (read `node_modules/next/dist/docs/` before touching routes or pages, per AGENTS.md), TypeScript, Supabase, Vitest + fast-check, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-19-rewards-design.md`

## Global Constraints

- XP: problem +10, first try +5, skill mastered in practice +100, session finished +20. Nothing for speed.
- 50 XP = 1 cube; 10 cubes = 1 rod = 1 level; `level = 1 + floor(xp / 500)`, `cubesInRod = floor((xp mod 500) / 50)`.
- Finished session = `ended_at` set **and** `state.problems >= 1`. Session day = `nyDay(state.lastActivity)`.
- Week = Sunday–Saturday, New York dates. Day played = a day with a finished session. Week goal = 3 days.
- Week streak = consecutive completed weeks ending last week that met the goal, +1 if this week already met it.
- Stickers never removed; values only go up; placement-only skills earn nothing; rewards never touch the engine.
- No reward text contains "lose", "lost", "miss", "break" or "broke" (any case). No text urges playing more now.
- No gendered pronouns in any copy (use the nickname or "the").
- `REWARDS` = `on` | `off`; unset or bad = `off` (warned once), same pattern as `env.speech`.
- Rewards failures never block play: render without rewards, `console.error` with the kid id only.
- Kid UI follows DESIGN.md: classroom materials, solid drop edges, Andika, kid text ≥ 22 px, focus rings, reduced-motion fallback with a still final state.

## Review Focus

1. **A session that crosses NY midnight or a DST change** — its day is `nyDay(lastActivity)`; weeks still split Sunday/Saturday correctly in the March and November DST weeks. (Task 2 tests.)
2. **Restored end card after Play again started a new (open, unfinished) session** — rewards must still be for the ended session, not shift. Unfinished/open sessions are ignored and "this session" is the latest finished one. (Task 2 test; Task 8 e2e reload.)
3. **Old sessions with missing or malformed state counters** (`problems` absent, `mastered` not an array) — counted as 0 / empty, never thrown. (Task 2 + Task 3 tests.)
4. **A kid with zero finished sessions** — Level 1, 0 cubes, empty chart; picker and child page still render, end card never asks for rewards. (Tasks 2, 5, 6 tests.)
5. **Long sticker labels and many new stickers at 390 px** — at most 3 stickers + "+N more", labels wrap, nothing scrolls sideways. (Task 4 test + Task 8 screenshots.)

### Task 2: `progress`, `gained`, `endRewards`

**Files:**
- Create: `src/domain/rewards/progress.ts`
- Test: `src/domain/rewards/progress.test.ts`, `src/domain/rewards/progress.property.test.ts`

**Interfaces:**
- Consumes: Task 1 exports; `nyDay` from `src/server/nyDay.ts` (no server-only import; safe in domain and client).
- Produces:
  ```ts
  export type SessionFacts = { startedAt: number; endedAt: number | null; lastActivity: number;
    problems: number; firstTryCorrect: number; mastered: string[] };
  export type MasteredAt = Record<string, number>; // skillId -> ms of skill_state.mastered_at
  export type EarnedSticker = { id: string; at: number };
  export type Week = { days: boolean[]; played: number; goalMet: boolean }; // days[0] = Sunday
  export type Progress = { xp: number; level: number; cubesInRod: number; week: Week;
    weekStreak: number; goalWeeks: number; stickers: EarnedSticker[] };
  export type Gained = { xp: number; levelBefore: number; levelAfter: number;
    cubesBefore: number; cubesAfter: number; newStickers: string[] };
  export type EndRewards = Gained & { week: Week };
  export function progress(sessions: SessionFacts[], masteredAt: MasteredAt, now: number): Progress;
  export function gained(before: Progress, after: Progress): Gained;
  /** Rewards for the latest finished session (by endedAt); null when there is none. */
  export function endRewards(sessions: SessionFacts[], masteredAt: MasteredAt, now: number): EndRewards | null;
  ```
- Rules the implementer must follow: only finished sessions count; `mastered` that isn't an array, or a non-number counter, counts as empty/0. Sticker `at` = the earning session's `lastActivity`. Topic sticker = all cluster skills in `masteredAt` **and** ≥1 skill sticker in that cluster; `at` = max(latest `masteredAt` in the cluster, earliest skill-sticker `at` in the cluster). Weeks: compute each session's NY date, then its week's Sunday NY date; `goalWeeks` counts every week (including this one) with ≥3 days. In `endRewards`, "before" = `progress(others, masteredAt filtered to times < this.startedAt, now)`, "after" = `progress(all, masteredAt, now)`; `newStickers` = after's ids not in before's.

- [ ] **Step 1: Write the failing table tests** (`progress.test.ts`, with a `session({...})` helper defaulting to a finished 1-problem session):
  - "XP adds problems, first tries, mastered skills and finished": one session `{problems: 15, firstTryCorrect: 10, mastered: ["add-within-10.make-ten"]}` → `xp === 15*10 + 10*5 + 100 + 20` (= 320), `level === 1`, `cubesInRod === 6`.
  - "level and cube boundaries": xp 499 → level 1, cubes 9; 500 → level 2, cubes 0; 550 → level 2, cubes 1 (build xp from problems counts).
  - "unfinished and empty sessions count for nothing": `endedAt: null` and `problems: 0` sessions → `xp === 0`, `stickers` empty.
  - "malformed counters count as zero": a session `{problems: undefined as never, mastered: "x" as never}` → no throw, `xp === 0` (problems counts as 0, so the session is not finished); a session `{problems: 3, firstTryCorrect: "2" as never, mastered: null as never}` → `xp === 3*10 + 20`.
  - "a session's day is its last activity in New York": a session with `lastActivity` = `2026-10-18T03:30:00Z` (Oct 17, 23:30 NY, a Saturday) lands on Saturday of the week starting Oct 11.
  - "weeks run Sunday to Saturday across DST": sessions on 2026-11-01 (DST ends, a Sunday) and 2026-11-07 fall in one week; 2026-03-08 (DST starts) likewise.
  - "week goal and streak": goal met in the weeks of Oct 4 and Oct 11, nothing yet in the week of Oct 18, `now` = Oct 19 → `weekStreak === 2`, `week.played === 0`, `goalMet === false`; add 3 days in the week of Oct 18 → `weekStreak === 3`.
  - "a missed week starts the count again": goal met weeks of Sep 27 and Oct 11, missed Oct 4 → `weekStreak === 1`; `goalWeeks === 2`.
  - "stickers and dates": first game on the first finished session; `skill:add-within-10.make-ten` dated to its session; `weeks:1` when the first goal week is met; `tries:10` when cumulative `problems - firstTryCorrect` reaches 10.
  - "placement-only skills earn nothing": a skill in `masteredAt` but in no session's `mastered` → no skill sticker, no +100.
  - "topic from practice plus placement": all `add-within-10` skills in `masteredAt`, one in a session's `mastered` → `topic:add-within-10` earned; with none in any session → not earned.
  - "endRewards is for the latest finished session and ignores an open one": two finished sessions + one `endedAt: null` session with problems → `newStickers`, `xp` match the second finished session only.
  - "no finished sessions": `endRewards([], {}, now)` is `null`; `progress([], {}, now)` is level 1, 0 cubes, 7 false days.
